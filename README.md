# oficina-de-integracao-2
Projeto extensionista desenvolvido para a disciplina de Oficina de Integração 2 (certificadora)


Para rodar o projeto, digite:

`npm run watch`

O God Mode fica desabilitado por padrão. Para habilitá-lo, crie um arquivo `.env` a partir do `.env.example` e defina `GOD_MODE=true`.

E acesse no navegador:

`localhost:9090`
